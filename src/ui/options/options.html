MailMind settings

AI connection

Any OpenAI-compatible server works: Ollama (http://localhost:11434/v1), LM Studio (http://localhost:1234/v1), llama.cpp server (http://localhost:8080/v1), vLLM…

Connection troubleshooting
  • 403 Forbidden from Ollama: set the Windows environment variable OLLAMA_ORIGINS to moz-extension://*, then quit and restart Ollama.
  • Short or forgetful answers: Ollama's default context window is small. Set OLLAMA_CONTEXT_LENGTH=16384 (or higher if your GPU allows) and restart Ollama.
  • LM Studio: start the local server and enable “CORS” in its server settings.
  • Server on another computer: use its LAN address; MailMind will ask for permission to reach it.

Behaviour

Automation (tagging and the briefing are off by default)

New emails (from the last 2 days, up to 50 at a time) get one MailMind tag. Every batch shows up under Recent actions and can be undone.

Add your own tag

If you pick the name of a tag you already have in Thunderbird, MailMind uses that tag.

Junk scores

Saves the AI’s opinion of each sender so clean-ups don’t ask about them again. Read-only: no email is changed. The background scan works back one month at a time and pauses whenever you use the chat or popups. “Not junk” and “👎 Junk” always override a saved score, and pressing Junk / Not Junk in Thunderbird makes MailMind judge that sender again.

Smart categories

Topics like “Kids’ school” or “Car”, noticed in your mail about once a week. Nothing is created until you approve it in the chat, and your own changes always win. They don’t change any email and don’t affect junk scores.

Shows a notification with unread mail, important emails and follow-ups. Click it to open the briefing in the chat. If Thunderbird is closed at that time, it runs when you next start it.

Follow-ups

Filter rules

Rules run automatically on new mail. Create them from the chat (“move newsletters to Reading”) or from the clean-up review.

Not junk

Senders you marked “Not junk” in the clean-up review. They're never suggested for deletion, the AI uses them as examples of mail you want, and AI-category rules skip them.

Junk

Senders you marked “👎 Junk” in the clean-up review. They always show up as junk, the AI uses them as examples of mail you don't want, and other senders from the same company lean towards junk. Marking a sender here never moves or deletes any email.

Recent actions

Everything MailMind changed. Deleted emails are in Trash and can be restored here.

Data

MailMind stores settings, rules, the undo history and search embeddings only inside Thunderbird. It never contacts anything except the AI server above.
